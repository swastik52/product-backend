Product Backend

A basic REST API for creating and retrieving products, built with Java 21, Maven, Spring Boot and MySQL.

Stack: Java 21 · Spring Boot 4.1.1 · Spring Data JPA · MySQL 8.4 · Maven

Getting started

Install JDK 21, Maven and Docker Desktop. Set JAVA_HOME to your JDK and start Docker Desktop.

Open PowerShell and start the database:

cd D:\CodeLife\ci-cd-git-aws
docker compose up -d
docker compose ps

Wait for the MySQL service to report healthy, then start the backend:

mvn spring-boot:run

The API is available at http://localhost:8080/api/products. Open this directory as a Maven project to run it from your IDE.

Database configuration

JDBC URLjdbc:mysql://localhost:3306/product

The Compose file initializes the database and stores its data in the mysql-data named volume. The backend reads its settings from src/main/resources/application.properties. Hibernate detects the database dialect and creates or updates the products table.

For a MySQL installation outside Docker, create the database manually:

CREATE DATABASE product CHARACTER SET utf8mb4;

To override the backend connection settings from PowerShell:

$env:SPRING_DATASOURCE_URL = 'jdbc:mysql://localhost:3306/product'
$env:SPRING_DATASOURCE_USERNAME = 'root'
$env:SPRING_DATASOURCE_PASSWORD = 'your-mysql-password'
mvn spring-boot:run

Use credentials matching your running database. Changing MYSQL_ROOT_PASSWORD in Compose does not reset the password in an already initialized database volume.

API endpoints

MethodPathResponse
GET/api/products200: product array ordered by ID; empty array when no products exist.
POST/api/products201: created product with a Location header.
GET/api/products/{id}200: product; 404 when the product does not exist.

Create a product

Send this JSON body to POST /api/products with Content-Type: application/json:

{
  "name": "Keyboard",
  "description": "USB keyboard",
  "price": 49.99
}
FieldValidation
idGenerated by the database; returned in responses.
nameRequired, nonblank, at most 150 characters.
descriptionOptional, at most 2,000 characters.
priceRequired, nonnegative, at most 10 integer digits and 2 decimal places.

Invalid request bodies or IDs return 400 Bad Request. Prices use Java BigDecimal and MySQL DECIMAL(12,2).

Try the API in PowerShell

$product = Invoke-RestMethod -Method Post -Uri 'http://localhost:8080/api/products' `
  -ContentType 'application/json' `
  -Body '{"name":"Keyboard","description":"USB keyboard","price":49.99}'

Invoke-RestMethod 'http://localhost:8080/api/products'
Invoke-RestMethod "http://localhost:8080/api/products/$($product.id)"

Build and test

mvn clean verify
java -jar target/product-backend-0.0.1-SNAPSHOT.jar

Automated tests exercise the HTTP layer and JPA persistence with a test-only H2 database in MySQL compatibility mode. They do not require a running MySQL server.

Manage MySQL

# View database logs
docker compose logs -f mysql

# Open the MySQL client; enter the configured root password when prompted
docker compose exec mysql mysql -u root -p

# Stop containers while retaining database data
docker compose down

Development notes

  • If port 3306 is occupied, stop the conflicting service or update the Compose host port and the JDBC URL together.
  • This basic API has no authentication. The example credentials are for local development.
  • Use versioned database migrations instead of ddl-auto=update for production.
